# Shelf Thread UX review and refresh plan (2026-11-01)

Method: read the theme, shared components, Home, Book detail, My Library and the root layout. The app was not run and there are no screenshots, so every finding below comes from the code. Check the visual ones on a device before building.

Brief: keep the warm, bookish feel (cream paper, forest green, Fraunces) and make it read as clean and modern. The identity is already good. The problems are inconsistency and clutter around it.

## What already works (keep)

- Fraunces for titles and Inter for UI is a coherent pairing, with a sensible scale (14/16/20/25/31/39) and 24px body line-height.
- Single-column, 720px reading width, 44pt targets, focus rings, labels on every control, and a hand-tuned dark theme.
- The "kicker" all-caps label is already gone (only a dead style in `theme.ts` remains). Delete it.

## Findings, most impactful first

1. **The feedback banner is the first thing on every screen.** `_layout.tsx` renders a bordered four-line box above the navigation header on every route. It costs roughly 100px of a phone screen on every page and makes each screen open with a survey ask. Show it once on Home with a dismiss button (remember the dismissal), and link the form from About and the footer.
2. **The header says too little and shouts in the wrong place.** The brand link is 14px, smaller than the 16px page title under it, and 25px on Home only (to-do 11). Detail pages are titled "Book", "Work", "Author" and "Subject", which says nothing the page doesn't already say. Fix: one wordmark at one size (about 20px Fraunces) on every screen, plus the actions. Show a second line only on utility pages (Settings, Lists, Import & Export), because detail pages already carry their own title in `DetailTop`.
3. **"My Library" holds no books.** `saved.tsx` is five text rows (Lists, Recommendations, Find Connection, Import & Export, Settings). The name promises a shelf. Make it the shelf: your lists first, as rows with a small cover stack and a count, with Hardcover on the top line (to-do 4). Move Import & Export and Settings into a quiet "Tools" group at the bottom. This matters more than any colour change.
4. **The palette is warm paper with cool greys.** Borders (`#e6e6ea`, `#eef0f2`), chips (`#f2f2f5`) and muted text (`#6b6b80`) are blue-tinted, so they sit slightly wrong on `#FAF7F0`. The dark theme repeats it: a blue-black `#191B20` paper with cream text. Tag chips use four hues (lavender, pink, orange, green) plus link blue. Warm every neutral, and cut the chips to two: genres in the green tint, subjects in a warm neutral. Links use the green.
5. **Detail pages mix alignments.** `DetailTop` centres the cover, title and actions, then every section below is left-aligned. `DESIGN_PLAN.md` already called for left alignment. On wide screens put the cover beside the title block. On phones keep it stacked but left-aligned.
6. **Two identical full-width green buttons cut through the reading flow.** "View as Graph" and "Find Connection" sit between About and Format. The graph is the product's main feature, so it should look like it: keep it primary and move it up with the other actions. "Find Connection" becomes a secondary outlined button.
7. **"Find This Book" is five identical link rows with a chevron.** Chevrons mean "go deeper in the app" everywhere else, but these leave the app. Use an external-link icon and group them under the call number. Hardcover (to-do 15) joins the group.
8. **Press feedback is only `opacity: 0.6`, in 22 places, with no web hover state.** On a cream page, faded text looks disabled. Use a tinted background on press and hover, through one shared row component.
9. **Radii and elevation are inconsistent.** There are radii of 4, 6, 10, 14 and 16, and the shadow style is used selectively. Settle on three radii (small 8, medium 14, pill) and use shadow only on covers and the centered modal.
10. **Loading is a bare spinner.** Use skeleton rows instead.

## Design plan

**Colour (light):**

| Token | Value | Use |
|---|---|---|
| Paper | `#FAF7F0` | page (keep) |
| Page edge | `#EFEAE0` | outside the 720px column |
| Card | `#FFFDF8` | covers, modal, raised rows |
| Rule | `#E6DFD0` | hairlines and borders (was cool grey) |
| Ink | `#262320` | text (warmed from `#1F2430`) |
| Muted ink | `#6B655A` | secondary text |
| Cover green | `#2B5951` | actions and links (keep) |
| Marginalia | `#A85026` | "yours" (saved) only (keep) |

The muted ink is a starting value. Run the contrast check against Paper and Card before locking it.

**Colour (dark):** replace the blue-black with a warm one. Paper `#1C1B18`, page edge `#121110`, card `#24221E`, rule `#34312B`, ink `#EDEAE2` (keep), cover green `#6FA897` (keep).

**Type:** Fraunces 600 for titles, Fraunces 500 for section headings and the wordmark, Inter for UI. No new fonts. The scale and line-heights stay. Stop setting list rows in Fraunces 600, which looks heavy at 16px. Use 500 there.

**Layout:** left-aligned, one column. Rows get 12px vertical padding and a warm rule. Utility screens (Settings, Backup) become grouped sections, with a heading and rows under it.

**The one memorable move, the thread.** The app is called Shelf Thread, and the Home "Recently looked at" list already draws a 6px node dot beside each row but never joins them. Join them with a thin `thread`-coloured line down the left edge, so recent items read as a path you followed. Reuse the same line, quietly, as the section divider on detail pages. Everything else stays calm.

**Home order:** wordmark with the tagline directly under it (to-do 6), then search first on web (scanning needs a camera, so it is a phone feature), with Scan as the green button on native. Then the threaded recents.

### Plan check against the defaults

- Cream + serif + green is the current identity and the brief asks to keep it, so it stays. It avoids the cream `#F4F1EA` and clay `#D97757` pair: the paper is `#FAF7F0`, the accent is green, and terracotta is used for nothing except "saved".
- A shelf-of-spines hero was considered and dropped: skeuomorphic, and spines need cover colours the app doesn't have. The thread is already in the product's name and graph.
- No eyebrow labels, numbered markers, ALL-CAPS tags or arrow suffixes are added. The new empty states say what to do next (for example, "Save a book from its page to start a list").

## Order of work

The in-flight plan (`docs/superpowers/plans/2026-11-01-library-and-hardcover-polish.md`) already rewrites the header (7), My Library (4, 5), About (12), the edit link (9, 10) and the save sheet (14). Doing the structural items first would conflict with it.

- **Phase A, now, no conflicts:** warm the neutral tokens in `themeColors.ts` (light and dark); drop the unused `kicker`; reduce chips to two hues; set the three radii; replace opacity feedback with a tinted press and hover state; dismissible feedback banner.
- **Phase B, after the polish plan merges:** wordmark-only header (finding 2), the shelf-style My Library (3), left-aligned detail header and re-ordered actions (5, 6), external-link rows (7), the thread on Home and as divider (design plan), skeleton loading (10).
